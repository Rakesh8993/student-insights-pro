# 📊 Student Insights Pro: Student Performance Analytics Dashboard

An interactive analytics dashboard and machine learning application built with **Python** and **Streamlit** to analyze, predict, and visualize student academic performance.

---

## 🚀 Key Features

- **📈 Exploratory Data Analysis (EDA):** Interactive charts showing student demographics, attendance, and study habits.
- **🤖 Machine Learning Predictions:** Predict student performance outcomes based on study hours, past grades, and attendance.
- **💡 Smart Recommendations:** Dynamic feedback and actionable guidance for students and educators.

---

## 🛠️ Tech Stack

- **Frontend / UI:** Streamlit
- **Data Processing:** Pandas, NumPy
- **Machine Learning:** Scikit-Learn
- **Data Visualization:** Matplotlib, Seaborn
